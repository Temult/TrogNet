# Contributing

The current scope is the public scaffold and publication tooling. Runtime work is
owned by E05R1 and must enter through the reviewed import procedure. Do not copy an
entire private application package into this repository.

Submit small pull requests with a clear purpose and local validation results. Use
synthetic examples and placeholders. Run the publication hygiene check before
submission. Contributions are accepted under Apache-2.0; submit only material you
have the right to contribute. Preserve third-party attribution where required.

Do not attach private research, credentials, personal paths, account identifiers,
evaluation data, or owner receipts. Mechanical checks do not replace owner review
of the complete final public diff. No contributor may infer runtime authorization
from a successful check, repository creation, or a merged documentation change.
